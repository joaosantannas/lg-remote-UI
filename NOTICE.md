# Créditos e avisos

## Projeto original

Este repositório é um fork do **[LG TV Controller](https://github.com/heroslender/lg-remote)**,
criado por **[heroslender](https://github.com/heroslender)**. Toda a base do app (conexão com
a TV, descoberta de dispositivos, banco de dados, navegação e a maior parte da lógica) é
trabalho do autor original.

O repositório original não declara uma licença. Os direitos sobre o código original
continuam com o autor. Este fork existe para uso pessoal e estudo; para redistribuir o app,
é necessária a autorização do autor original.

## Alterações deste fork

Feitas por [João Santanna](https://github.com/joaosantannas): novo visual escuro e minimalista
em todas as telas, tela de controle com touchpad, botões de mídia, botão que abre um app
específico da TV, apps em duas fileiras, organizador de apps e novo ícone.
